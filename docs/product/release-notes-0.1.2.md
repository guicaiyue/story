## 版本亮点

### 1. 平板不再是大号手机

| 场景 | 之前（0.1.1） | 现在（0.1.2） |
| --- | --- | --- |
| 导航 | 底部导航横跨整块屏幕 | 宽度 ≥ 900 时挪到**左侧**，拇指不用跨屏 |
| 正文 | 一行字横跨 1100px+ | 内容页收窄到 720 / 960 并**居中** |
| 卡片 | 手机尺寸，平板上显得稀 | 分类卡 150/170/190、故事卡 200/220/240 随档位放大 |
| 全幅页面 | — | 主壳 / 播放器 / 启动页仍铺满，不被收窄 |
| 播放器 | 竖排，封面占满一屏 | 平板：左栏封面 + **今晚的列表**，右栏控制；手机保持原样 |

屏幕分三档：手机 **< 600**、小平板 **600–899**、平板/桌面 **≥ 900**。

### 2. 发布信息

- 服务端与后台已上线：`api-story.xirizhi.cn` / `admin-story.xirizhi.cn`（HTTPS，healthy）；
- 生产库迁移 5/5 应用、专用库账号 `story_app`（无 DDL 权限）、首个管理员已建；
- APK 用**正式签名**出包（0.1.0/0.1.1 的 debug 签名到此为止）。

### 3. 其余沿用 0.1.1（无变化）

- 9 屏：启动 / 首页 / 分类 / 故事详情 / 播放器 / 我的 / 家长门 / 家长中心 / 夜间播放器；
- 首页按年龄档推荐（3-6 / 6-9 / 9+），9+ 内容不进儿童端；
- 音频由服务端按需 TTS 合成（`zh-CN-YunxiNeural`，语速 -10%），支持拖动与续播；
- 收藏、播放进度、家长设置（时长限制 / 年龄档 / 睡眠定时）；
- API 基址编译期固定为 `https://api-story.xirizhi.cn`。

### ⚠️ 0.1.2 的已知限制

- 「今晚的列表」＝ 自己加的（存本机）+ 同年龄档推荐；可切播、移出、↑↓ 调顺序；
- 平板断点是工程口径，`docs/design/android-app` 里目前没有平板设计稿（见 `17-tablet-support.md` §2）；
- 真实短信通道未接，仍用服务端固定验证码（`FIXED_SMS_CODE`）；上架前接入并回收。

## 安装说明

1. 下载 `storynook-0.1.2.apk`；
2. 允许「安装未知来源应用」（未上架商店）；
3. 安装并打开，无需注册（游客身份）。

| 项 | 值 |
| --- | --- |
| 系统 | Android 7.0（API 24）及以上 |
| 架构 | arm64-v8a、armeabi-v7a、x86_64 |
| 包名 | `com.storynook.app` |

> ⚠️ **前置条件**：API 基址在编译期固定为 `https://api-story.xirizhi.cn`。
> 该域名需要先完成生产 docker 部署并挂上反代，否则装上后所有请求都会失败。
