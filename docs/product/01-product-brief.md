# 小故事铺 2.0 · 产品 Brief

> 一句话：**给中国家庭的「睡前 20 分钟」——孩子自己会听，妈妈放心去忙。**
> 本文是开发会话的唯一产品依据；与代码冲突时以本文为准，改本文要先改文档再改代码。

## 1. 定位

从「静态故事展示站」升级为「亲子音频故事平台」：

- **服务端**：内容、用户、播放、推荐、运营的唯一事实源。
- **Web 后台**：给运营/编辑用的内容管理与数据看板。
- **安卓 App**：孩子听故事的入口 + 家长的控制台。

非目标（本期明确不做）：社交/评论/UGC、直播、硬件、多端（手表/车机）、付费订阅体系（只留接口，不做支付）。

## 2. 目标用户与场景

| 角色 | 场景 | 成功的样子 |
| --- | --- | --- |
| 孩子 3–9 岁 | 睡前、路上、放学后 | 自己点开就能听，不用识字，不用叫妈妈 |
| 妈妈 28–45 岁 | 20:30–21:30 睡前流程 | 1 次点击开始，不用守着；知道孩子听了什么 |
| 女性泛用户 | 孩子睡后 / 通勤 | 一个安静、好看、不打扰的声音空间 |
| 运营/编辑 | 每天上午 | 在后台完成「选品—审核—上架—看数」闭环 |

## 3. 三端范围（MVP）

### 3.1 服务端（Node 22 + TypeScript + Fastify + Prisma + PostgreSQL）

必须交付：

1. **内容域**：故事（story）、分类（category）、年龄分级（ageBand 3-6 / 6-9 / 9+）、标签、时长、封面、状态（draft/review/published/archived）、音频资源（先接 TTS 合成结果，允许空）。
2. **用户域**：手机号/游客账号、家庭（family）、儿童档案（child：昵称、生日、头像、年龄档）、家长门配置。
3. **播放域**：播放进度（progress）、收藏（favorite）、历史（history）、睡前定时设置、每日时长限制、播放事件（play event，供分析）。
4. **运营域**：首页推荐位（banner/精选/场景歌单）、分类排序、每日推荐。
5. **后台 API**：管理端鉴权（JWT + 角色 admin/editor）、内容 CRUD 与审核流、用户/儿童查询、数据看板聚合、操作审计（audit log）。
6. **兼容**：保留 pREST 只读通道用于老站，但新服务端是事实源；老站数据迁移脚本。
7. **质量**：OpenAPI 文档、种子数据（从 2197 条真实内容导入）、单元/接口测试、Docker Compose 一键起。

### 3.2 Web 后台管理（React 18 + Vite + TypeScript + Ant Design 5）

页面（MVP）：

1. 登录 + 角色
2. 数据看板：今日播放/听众人数/完播率/新增家庭/内容健康度（待审、缺封面、无音频）
3. 内容管理：列表（筛选/搜索/批量）、编辑器（正文、分类、年龄档、标签、封面、音频、状态）、审核（提交/通过/驳回）
4. 分类与推荐位管理：分类排序、首页推荐位配置
5. 用户与儿童：家庭列表、儿童档案、播放记录只读
6. 数据中心：播放趋势、内容 Top、分类分布、时段分布
7. 系统：管理员账号、操作日志、TTS 任务（可选）

### 3.3 安卓 App（Flutter 3 + Dart）

页面（MVP）：

1. 启动/加载（品牌 + 温暖感）
2. 首页：今晚推荐（大卡片）、场景入口（哄睡/叫早/出行）、继续听、分类
3. 分类/搜索：年龄档筛选、时长筛选
4. 播放器：大封面、播放/暂停、进度、定时（15/30/45/听完这集）、锁屏控制、自动下一集
5. 故事详情：简介、时长、年龄档、收藏、开始听
6. 我的：继续听、收藏、历史、儿童档案
7. 家长门：算术题进入
8. 家长中心：时长限制、内容年龄档、播放报告、退出儿童模式
9. 设置：缓存管理、关于、隐私政策

## 4. 关键体验（必须做对的 6 件事）

1. **一键开始**：首页第一屏一个「今晚听什么」大按钮。
2. **续播**：打开 App 直接能接着上次听。
3. **失败兜底**：网络断开时用缓存，不白屏；音频加载失败给重试与换一个。
4. **睡前不刺眼**：夜间模式自动（21:00 后），音量渐弱，播完自动停。
5. **家长门**：付费/设置/退出儿童模式必须过门；门是可配置的。
6. **内容安全**：默认只展示 published 且 ageBand 匹配的内容；恐怖/怪谈类默认不进入儿童端。

## 5. 设计语言

- **气质**：温柔、安静、有纸感。参考「绘本 + 深夜台灯」，不是「儿童乐园」。
- **色彩**：暖米白底（#FBF7F0 一类）、主色低饱和暖橙/赭（#D98E5A 一类）、文字暖黑（#3A3330）；夜间模式深靛（#1E1B2E 一类）。禁用高饱和糖果色。
- **字体**：中文 MiSans（站点已用）；标题衬线可选中性宋体感，正文无衬线。
- **圆角与留白**：卡片 16–24px 圆角，页面留白充足；儿童端触控目标 ≥ 64pt。
- **图标**：线性 + 圆角，不用复杂插画堆砌；允许一个固定 IP 角色（现有 Live2D 可作彩蛋，不做核心）。
- **动效**：轻、慢、少；不做弹跳和强反馈。

## 6. 成功指标（MVP 验证期）

| 指标 | 定义 | 目标 |
| --- | --- | --- |
| 激活 | 新装 → 首次播放 | ≥ 60% |
| 次日留存 | 首次播放次日再听 | ≥ 30% |
| 睡前场景占比 | 20:00–23:00 播放 / 总播放 | ≥ 50% |
| 完播率 | 播放 ≥ 90% / 开始播放 | ≥ 45% |
| 家长门通过率 | 通过家长门 / 触发家长门 | 记录基线 |
| 内容健康 | published 中缺封面/无音频/无年龄档占比 | ≤ 5% |
| 运营效率 | 单篇内容从入库到上架耗时 | ≤ 5 分钟 |

## 7. 技术选型与理由

| 层 | 选型 | 理由 |
| --- | --- | --- |
| 服务端 | Node 22 + TS + Fastify + Prisma + PostgreSQL | 与现有 PG/pREST 同库，迁移成本低；TS 与前端同语言；Prisma 让 agent 改 schema 可控 |
| 后台 | React 18 + Vite + TS + Ant Design 5 | 中文后台事实标准，表格/表单/权限齐全，避免手搓组件 |
| App | Flutter 3 + just_audio + drift | 单代码库可出安卓；音频/离线生态成熟；设计还原度高 |
| 部署 | Docker Compose + nginx | 与 NAS 现有部署一致，可被 n8n/Watchtower 接管 |
| 监控 | 服务端结构化日志 + 播放事件表 | 先自建，不引入重监控 |

## 9. 决策记录（产品负责人已定，不再反复讨论）

- 内容以**官方精选**为主，不做 UGC。
- 儿童端**不接广告**、不做社交、不做排行榜。
- 付费暂不实现，但数据模型预留 `entitlement`。
- 老站（静态页 + pREST）保留可访问，作为内容预览入口，逐步被 App 取代。
- 恐怖/怪谈类内容**默认不在儿童端出现**，后台保留但不进推荐池。
