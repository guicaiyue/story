## 1. 查出并修掉的两个真问题

### ① 顶部标题栏把第一行内容盖住了（3 屏受影响）

- **现象**：分类屏的「年龄档」标签整块消失、筛选芯片被切掉一半；家长中心、故事详情同样被压。
- **根因**：`.phone-content` 已经用 `padding-top: 52px` 让出状态栏安全区，
  而 `.topbar` 又写了 `top: var(--phone-safe-top, 52px)` —— 安全区被让了两次，
  吸顶标题栏整体下移 52px，正好压在下面的内容上。
- **修法**：`.topbar { top: 0 }`（安全区只由容器让出）。
- **验证**：分类屏恢复「年龄档」标签 + 完整芯片；家长中心标题不再与副标题重叠。

### ② 每屏标题都带一圈焦点框

- **现象**：首页「晚上好，今晚想听什么？」、播放器标题外面有一圈橙色圆角框。
- **根因**：切屏时 JS 把焦点移到 `h1`（供读屏软件播报，`tabindex="-1"`），
  而全局 `:focus-visible` 规则给所有可聚焦元素画了焦点环。
- **修法**：`[tabindex="-1"]:focus, [tabindex="-1"]:focus-visible { outline: none }`
  —— 程序化聚焦不是键盘导航的落点，不该画框；真正的键盘控件仍保留焦点环。

## 4. 复现方式（已脚本化）

```bash
./scripts/design-shots.sh              # 17 张：手机 9 屏 + 平板 1 屏 + 后台 7 视图
./scripts/design-shots.sh admin        # 只渲后台
```

脚本：`scripts/design-shots.sh`（宿主侧，负责挂载与产物回收）+ `scripts/design-shots.cjs`
（容器内，puppeteer 渲染）。用法、加新原型的方法、四个坑写在 `docs/design/README.md`。

脚本要点（踩过的三个坑）：

1. `/out` 必须 `chmod 777`——容器里跑 chrome 的不是 root；
2. 不要用 `-p 13001:3000` 走 HTTP API，端口常被占；直接 `node -e/脚本` 更省事；
3. **每屏重新 `goto`**，同一个 page 连续改 hash 会带着上一屏的滚动/过渡状态，截出来是错的
   （分类屏的「芯片被裁」一开始就是被这个假象误导的）。
